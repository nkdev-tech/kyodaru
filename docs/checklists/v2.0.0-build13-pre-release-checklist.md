# v2.0.0 リリース前チェックリスト（TestFlight 実機検証）

> 対象リリース: v2.0.0 / 関連: #15
>
> 目的: v2.0.0 をリリースする前に、TestFlightで配布したビルドを実機で操作し、利用者がストレスなく使えることを確認する。
>
> このビルド（build13, commit `aac98cb`）はPR #127（release/2.0.0 → main）のマージにより自動CD（EAS Build）でビルドされた最初の2.0.0ビルド。1.0.0（build9）以降の主な変更点：
> - **プロンプトインジェクション対策**（#100・破壊的変更）— `/api/ai` に認証必須化、入力上限（rawText 50,000文字／messages[].text 1,000文字／messages配列40件）、AI出力上限（maxOutputTokens）を追加。これに伴い `MIN_SUPPORTED_APP_VERSION` を `2.0.0` に更新（**1.0.1以下のクライアントは今後強制アップデート対象**）
> - **アプリサイズ削減**（#95）— フォント未使用ウェイト・未使用パッケージ `expo-image`・未使用 `splash-icon.png` を削除
> - **ホーム画面レイアウト調整**（#96）— レイアウトバランス・配色を調整（iPhone SE等の低背端末向けの閾値`COMPACT_HEIGHT_BREAKPOINT`を追加）
> - App Store言語表示を日本語化（`CFBundleDevelopmentRegion`・`locales/ja.json`）※App Store Connect側のメタデータ確認であり、本チェックリストの実機操作では直接確認できない
>
> 各項目を実機で確認し、`[ ]` を `[x]` に更新する。問題があれば末尾の「検出した問題」に記録する。
