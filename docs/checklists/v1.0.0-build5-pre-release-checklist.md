## 1. インストール（完了条件: TestFlight経由でインストールできる）

- [ ] TestFlightアプリに対象ビルドが表示される
- [ ] 「インストール」でダウンロード・インストールが完了する
- [ ] ホーム画面にアプリアイコンが正しく表示される（アイコン・アプリ名の崩れがない）
- [ ] アプリを起動でき、スプラッシュ画面から正常にホーム画面へ遷移する

## 2. 起動・初期化

- [ ] 起動時にスプラッシュが表示され、フォント読み込み後にコンテンツが表示される
- [ ] 初回起動で匿名サインインが完了し、エラーなくホーム画面が使える
- [ ] 天気パネルに気圧・気温・天気が表示される（位置情報の取得待ちでも最終的に表示される）
- [ ] （該当する場合）古いバージョン判定の強制アップデート案内が誤って出ない

## 3. ぼやき → AI返信 → 保存（完了条件: 一連の操作がストレスなく行える）

- [ ] ホームでぼやき入力（チャット）を開ける
- [ ] チャットを開くとAIの初回メッセージ（例:「今日の体調はいかがですか？」）が表示される
- [ ] テキストを入力でき、キーボードで入力欄が隠れない（KeyboardAvoiding が機能している）
- [ ] 送信するとAIの返信が返ってくる（待ち時間が長すぎない・ストレスがない）
- [ ] 送信した内容が今日の記録として保存され、ホームの一覧に反映される
- [ ] 記録に体調フェイス・体調ラベル・要約が表示される
- [ ] 1日の記録上限に達した場合の挙動が適切（上限到達時に入力が抑止される）
- [ ] 通信失敗時にエラートースト（例:「送信に失敗しました」）が出て、アプリが落ちない
- [ ] 連続送信・素早い操作でも UI がもたつかない・固まらない

## 4. カレンダー（完了条件: 実装済み画面が問題なく表示・操作できる）

- [ ] カレンダータブに切り替えられる
- [ ] 当月のカレンダーが正しく表示される（曜日・日付の並びが正しい）
- [ ] 記録のある日に天気アイコン・体調フェイスが表示される
- [ ] 左スワイプで翌月、右スワイプで前月に移動できる（アニメーションが滑らか）
- [ ] 当月より先には進めない／下限（2016年1月）より前には戻れない
- [ ] 日付をタップすると詳細（体調・天気・気圧 hPa・要約）が表示される
- [ ] 記録のない日をタップしても破綻しない

## 5. 設定タブ（完了条件: 実装済み画面が問題なく表示・操作できる）

- [ ] 設定タブに切り替えられる
- [ ] アプリバージョン（`v...`）が表示される
- [ ] 「アカウント設定」に遷移でき、ユーザーIDが表示される
- [ ] ユーザーIDのコピーが機能する
- [ ] アカウント設定から戻る操作ができる
- [ ] 「プライバシーポリシー」をタップするとブラウザでページが開く

## 6. 全体品質（完了条件: 明らかな表示崩れ・クラッシュがない）

- [ ] タブ間の移動がスムーズで、状態が保持される
- [ ] 文字切れ・はみ出し・余白崩れなどの明らかなレイアウト崩れがない
- [ ] セーフエリア（ノッチ・ホームインジケータ）にUIが被っていない
- [ ] アプリをバックグラウンド→フォアグラウンド復帰しても状態が壊れない
- [ ] 一連の操作を通してクラッシュ・フリーズが発生しない
- [ ] （ダーク/ライト両対応の場合）表示モードを切り替えても破綻しない
